# Enterprise Publishing Management System (EPMS)

## Overview

The Enterprise Publishing Management System (EPMS) is a web-based application designed to support the operations of a book publishing house. It aims to streamline the publishing lifecycle, from manuscript submission and editorial review to book production, inventory, sales, and royalty management.

## Key Features

- Author and manuscript management
- Editorial assignments, reviews, and revision tracking
- Book design and production workflow
- Author preview and approval of book designs
- Production quality control and readiness for printing
- Inventory, sales, and royalty management
- Role-based access control for system users

## Technology Stack

- **Backend:** Java 21, Spring Boot
- **Security:** Spring Security, JWT-based authentication
- **Database:** MySQL
- **Persistence:** Spring Data JPA, Hibernate
- **Database Migrations:** Flyway
- **Build Tool:** Maven
- **Frontend:** HTML, CSS, JavaScript

*Verify each technology against the final implementation before publishing this README.*

## Project Structure

- `epms/` — Application source code and Maven configuration
- `docs/` — Technical documentation, reports, specifications, and diagrams
- `database/` — Database schema or sanitized sample SQL export

## Getting Started

1. Install Java 21 and MySQL.
2. Create a local MySQL database.
3. Configure the database connection using local environment-specific configuration.
4. Apply the required database schema and migrations.
5. Run the application using the Maven wrapper or your preferred IDE.

Refer to the project's configuration and documentation for the exact setup instructions. Never use production credentials in a local configuration or commit secrets to version control.
